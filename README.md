# My Fullstack Journey

> 从零基础到 AI 时代全栈工程师的学习记录。

## 目标

- 用 12-18 个月完成 Python、JavaScript、HTML/CSS、React、后端、数据库、LLM 与 AI Agent 的系统学习。
- 每个阶段都以可运行、可展示的项目收尾，而不是只看教程。
- 每周至少 5 天提交真实代码，保持稳定的学习节奏。
- 最终能够独立设计、开发、部署并迭代一个 AI Agent 产品。

## 使用 AI 的原则

1. 第一次接触的概念，先读官方文档 30 分钟。
2. 卡住先独立尝试 15 分钟，再向 AI 描述报错、假设和已尝试方案。
3. 不直接索要完整答案，优先要求指出方向。
4. AI 给出的代码必须逐行解释，并能在关闭 AI 后重写。
